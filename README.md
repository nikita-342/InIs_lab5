# Запуск


1. Откройте терминал в папке `lab5`.
2. Установите зависимости:

```bash
npm install
```

3. Запустите сервер разработки:

```bash
npm run dev
```

4. Откройте в браузере адрес `http://localhost:5173`.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

Корзина хранится в `src/store`. `ProductCard` отправляет действие `addToCart`, `CartIcon` читает общее количество товаров через `useSelector`. Компоненты друг с другом не связаны.
